### Shirocho · 白蝶

I build small, careful things for the web, with one design language down to the pixel.

**[shirocho.com](https://shirocho.com)** is my blog, built with Astro in Material 3 Expressive and served by Cloudflare Workers. It's fast and readable offline, has no trackers, and its pages load nothing from other servers.

`TypeScript` `Astro` `Cloudflare Workers` `Durable Objects`
